# Disarm Mod

A Minecraft Forge mod for version 1.20.1 that adds items to disarm and equip mobs.

## Features

### Disarm Wand (缴械法杖)
- Uses Nether Star texture
- Right-click on any living entity to make them drop all their armor and held weapons
- Works on all mobs including players
- Has a short cooldown after use

### Equip Wand (装备法杖)
- Uses Blaze Rod texture
- Right-click on any mob to give them random armor and weapons
- Randomly selects from all armor tiers (Leather to Netherite)
- Randomly selects weapons (Swords, Axes, Bows, Crossbows, Tridents)
- 30% chance to also give a shield
- All equipped items have 100% drop chance

## Installation

1. Make sure you have Minecraft Forge 1.20.1 (47.2.0+) installed
2. Download the mod JAR file from releases
3. Place the JAR file in your `mods` folder
4. Launch Minecraft with Forge

## Building from Source

```bash
./gradlew build
```

The built JAR will be in `build/libs/`

## Creative Tab

Both items are available in a custom creative tab called "Disarm Mod" (缴械模组)
